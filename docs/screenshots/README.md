# Screenshots

The main [`README.md`](../../README.md) stages the embeds below but keeps them
commented out until the real media lands here, so the README never shows broken
images. Filenames are fixed: drop the files in with the same names, then
uncomment the three embeds in the README's "See it" section.

| File | What to capture | Suggested format |
|------|-----------------|------------------|
| `balance-scale.gif` | The balance-scale step: removing the same weight from both pans and the scale rebalancing in real time | Short looping GIF (a few seconds) |
| `tile-sorting.png` | The tile-combine step: like terms grouped into the combine box | PNG still |
| `treasure-map.png` | The home screen: the treasure-map course path with streak, XP, and level | PNG still |

Capture on a narrow (mobile) viewport where possible so the images read well on
GitHub. Keep each file under ~3 MB so the repo stays light.
